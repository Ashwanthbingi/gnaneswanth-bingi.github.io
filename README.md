# Gnaneswanth Bingi — Portfolio

Welcome to my personal portfolio website, built with [Astro](https://astro.build/) and [GSAP](https://gsap.com/).

## Features
- **Modern Design**: Premium aesthetics, smooth gradients, and custom layouts.
- **Micro-animations**: Interactive elements animated using GSAP and Lenis scroll.
- **Fast Performance**: Fully static site built with Astro.
- **GitHub Pages**: Automatically deployed via GitHub Actions.

## Development

To run this project locally:

```bash
# Install dependencies
npm install

# Start the local development server
npm run dev
```

## Deployment

The site is built and deployed automatically to GitHub Pages on every push to the `main` branch via GitHub Actions.
